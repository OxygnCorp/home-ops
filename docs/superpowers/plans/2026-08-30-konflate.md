# konflate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deploy konflate (rendered Flux PR review UI) to the `flux-system` namespace via its official OCI Helm chart, with Mushu-bot GitHub App auth, write-back, MCP endpoint, and internal-only exposure.

**Architecture:** Standard repo pattern — Flux Kustomization (`ks.yaml`) pointing at an `app/` dir containing OCIRepository (chart source), HelmRelease (values), and ExternalSecret (PEM key from 1Password item `github`). UI exposed via the chart's native HTTPRoute on Gateway `envoy-internal`. No tests in the classic sense: validation is `flate test`/`flate diff` (the repo's pre-push guard), TDD-style red/green is replaced by validate-before/after.

**Tech Stack:** Flux v2 (Kustomization, HelmRelease v2, OCIRepository), external-secrets (ClusterSecretStore `onepassword`), Gateway API HTTPRoute, konflate chart `0.3.0` from `oci://ghcr.io/home-operations/charts/konflate`.

```yaml
---
# yaml-language-server: $schema=https://k8s-schemas.home-operations.com/helm.toolkit.fluxcd.io/helmrelease_v2.json
apiVersion: helm.toolkit.fluxcd.io/v2
kind: HelmRelease
metadata:
  name: konflate
spec:
  interval: 1h
  chartRef:
    kind: OCIRepository
    name: konflate
  install:
    remediation:
      retries: -1
  upgrade:
    cleanupOnFail: true
    remediation:
      retries: 3
  values:
    deploymentAnnotations:
      reloader.stakater.com/auto: "true"
    config:
      repo: github://OxygnCorp/home-ops
      refreshInterval: 10m
      appClientId: Iv23lizpdaSYJBX0uzo8
      statusChecks: true
      prComments: true
      publicUrl: https://konflate.oxygn.dev
      mcp: true
      verifyImages: true
    secret:
      existingSecret: konflate
    httpRoute:
      enabled: true
      parentRefs:
        - name: envoy-internal
          namespace: network
      hostnames:
        - konflate.oxygn.dev
    persistence:
      enabled: true
      size: 5Gi
    monitoring:
      serviceMonitor:
        enabled: true
    resources:
      requests:
        cpu: 200m
        memory: 512Mi
      limits:
        memory: 2Gi
```

# OpenCost Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deploy OpenCost OSS in `observability` for per-namespace/workload cost allocation with AWS us-east-1 reference pricing, exposed via `opencost.oxygn.dev` and wired into Prometheus (ServiceMonitor) so `radar-get_cost` works.

**Architecture:** Vendor Helm chart (`opencost` 2.5.33, exporter+UI+MCP) deployed via Flux following the `blackbox-exporter` pattern (NOT app-template). OpenCost scrapes the existing kube-prometheus-stack Prometheus; a ServiceMonitor makes OpenCost's own metrics scrapeable back, and grafana-operator CRDs pin the three official OpenCost dashboards.

**Tech Stack:** Flux (OCIRepository, HelmRelease, Kustomization), openhands chart `oci://ghcr.io/opencost/charts/opencost`, kube-prometheus-stack Prometheus, grafana-operator, Envoy Gateway (`envoy-internal` internal route), flate validation.

**Spec:** `docs/superpowers/specs/2026-10-28-opencost-design.md`

## Global Constraints

- Chart: `oci://ghcr.io/opencost/charts/opencost`, tag `2.5.33`, layerSelector chart-tar+gzip.
- Namespace: `observability` (injected by app `kustomization.yaml` `namespace:`; NEVER set `metadata.namespace` inline on HelmRelease/OCIRepository/Kustomization).
- App dir pattern: `kubernetes/apps/observability/opencost/{ks.yaml, app/*}`.
- `ks.yaml`: `targetNamespace: observability`, `interval: 1h`, `wait: false`, `prune: true`, sourceRef GitRepository `flux-system` @ `flux-system`.
- HelmRelease: `interval: 1h`, `install.remediation.retries: -1`, `upgrade.cleanupOnFail: true` + `upgrade.remediation.retries: 3`.
- Custom pricing = **hourly USD**: CPU `0.048`, spotCPU `0.0144`, RAM `0.012`, spotRAM `0.0036`, GPU `0.95`, storage `0.0001096`, zoneNetworkEgress `0.01`, regionNetworkEgress `0.01`, internetNetworkEgress `0.12`. Sanity: cluster total ≈ $2 000–3 500/month.
- Prometheus URL: `http://kube-prometheus-stack-prometheus.observability.svc.cluster.local:9090` (external; internal disabled).
- UI route native chart values (`opencost.ui.httpRoute`), parentRef `envoy-internal` @ namespace `network`, hostname `opencost.oxygn.dev`. MCP (8081) stays unexposed. No standalone HTTPRoute manifest.
- No adjective secrets: no ExternalSecret needed.
- Images: chart default digest pins (exporter/UI 1.121.3) — do not override tags.
- NetworkPolicies: left disabled (chart default).
- GrafanaDashboard CRD pattern: `allowCrossNamespaceImport: true`, `instanceSelector.matchLabels: {grafana.internal/instance: grafana}`, `datasources: [{datasourceName: prometheus, inputName: DS_PROMETHEUS}]`, pin by `url: https://grafana.com/api/dashboards/<id>/revisions/<rev>/download`. Dashboards: **22208 rev 8 (Overview), 22252 rev 8 (Namespace), 25168 rev 2 (Workload)** — verified via grafana.com API 2026-10-28; manifest embedded in Task 3.
- No toleration/nodeSelector for `k8s-3` AI taint (pods land on CP nodes like the rest of the stack).
- Validation gates: `mise exec -- flate test hr --path ./kubernetes/apps/observability/opencost` must pass before each commit; `helm template` render sanity before commit; `diff_kubernetes_manifest` against the live cluster before pushing.

```yaml
---
# yaml-language-server: $schema=https://k8s-schemas.home-operations.com/source.toolkit.fluxcd.io/ocirepository_v1.json
apiVersion: source.toolkit.fluxcd.io/v1
kind: OCIRepository
metadata:
  name: opencost
spec:
  interval: 15m
  layerSelector:
    mediaType: application/vnd.cncf.helm.chart.content.v1.tar+gzip
    operation: copy
  ref:
    tag: opencost-2.5.33
  url: oci://ghcr.io/opencost/charts/opencost
```

- [ ] **Step 3: Create HelmRelease with full values**

`kubernetes/apps/observability/opencost/app/helmrelease.yaml`:

```yaml
---
# yaml-language-server: $schema=https://k8s-schemas.home-operations.com/helm.toolkit.fluxcd.io/helmrelease_v2.json
apiVersion: helm.toolkit.fluxcd.io/v2
kind: HelmRelease
metadata:
  name: opencost
spec:
  interval: 1h
  chartRef:
    kind: OCIRepository
    name: opencost
  install:
    remediation:
      retries: -1
  upgrade:
    cleanupOnFail: true
    remediation:
      retries: 3
  values:
    opencost:
      prometheus:
        internal:
          enabled: false
        external:
          enabled: true
          url: http://kube-prometheus-stack-prometheus.observability.svc.cluster.local:9090
      metrics:
        serviceMonitor:
          enabled: true
      customPricing:
        enabled: true
        createConfigmap: true
        costModel:
          description: AWS us-east-1 on-demand reference (m5-class compute, EBS gp3)
          CPU: "0.048"
          spotCPU: "0.0144"
          RAM: "0.012"
          spotRAM: "0.0036"
          GPU: "0.95"
          storage: "0.0001096"
          zoneNetworkEgress: "0.01"
          regionNetworkEgress: "0.01"
          internetNetworkEgress: "0.12"
      ui:
        httpRoute:
          enabled: true
          parentRefs:
            - name: envoy-internal
              namespace: network
          hostnames:
            - opencost.oxygn.dev
      mcp:
        enabled: true
```

- [ ] **Step 4: Create ks.yaml**

`kubernetes/apps/observability/opencost/ks.yaml` (mirror blackbox-exporter's exactly, name/rules adapted):
